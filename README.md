
# 授業が始まるまでのカウントダウンタイマー

# for version 1.0.0  
　このHTMLは授業開始までの時間をタイマーに表示するものです。その下は今日の日付を年/月/日/曜と表示していて、時刻も24H形式で表示しています。時刻は日本標準時です。

3.使い方  
4.利用規約

---  
### 1.誤差調節機能について  
　誤差調節機能(1.の中では[この機能]と略します)とは、学校の時間(チャイム)がズレているときにそのズレをタイマーに適用する機能です。この機能はタイマーの時間のみ変更し、現在時刻は変化しません。+が大きくなるほどタイマーが早くなり、-が大きくなるほどタイマーが遅くなります。
---  
### 2.全画面表示機能について  
　全画面表示機能(2.の中では[この機能]と略します)とは、この授業タイマーのみ表示したいときに選択すると他のタブなどを表示せずに利用することができます。大画面で移したいときなどにこの機能を利用してください。
---  
## 3.使い方  
　起動すると時間割に従ったタイマーがついています。デフォルトでは誤差が0秒になっていますが、チャイムがなる時間はその時によって異なるのでその都度変更してください。授業が始まると授業が終わるまでのタイマーに切り替わります。土曜日・日曜日・祝日はタイマーが動きません。また授業がすべて終わると\[本日の授業は終了しました\]と表示されます。
