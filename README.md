# Countdown timer until class begins

日本語のREADEMEはこちら[./READEME.ja.md]

## For version 1.1.0
  　This HTML timer displays the remaining time until class starts. 
  Below that, it shows today's date in the format of year/month/day/week and displays the time in 24-hour format. The time is based on Japan's Standard Time.

#### 1. About the Error Adjustment Function
  The error adjustment function (referred to as [this function] in section 1) is a feature that can adjust the difference of the timer when school bell time is off. This function only changes the timer's time, the current time remains unchanged. The larger the positive value, the faster the timer runs.

---
#### 2. About the Full-Screen Display Function
  The full-screen display function (referred to as [this function] in section 2) allows you to use the school timer without displaying other tabs or windows when you wish to view only this timer. Please use this function when you wish to display it on a large screen.

---
#### 3. About Settings Function
  Settings function allow you to adjust notification volume or toggle notifications on or off. The default notification volume is [100], and the default notification setting is [Notify]. Use these functions when you want to lower the volume or when notifications become disruptive.

---
## 4. How To
  Upon startup, an timer based on the schedule is activated. By default, the margin of error is set to 0 seconds, but since the chime time varies each time, please adjust it accordingly. When class begins, the timer switches to count down until the end of class. This timer does not run on Saturdays, Sundays, and holidays. Additionally, once all classes have ended, \[Today's classes have ended\] will be displayed.
